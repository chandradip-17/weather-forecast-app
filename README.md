# 🌦️ Atmos — Modern Weather Dashboard

A beautiful, responsive weather forecasting web application built with **HTML, CSS, and JavaScript**. Atmos provides real-time weather information, hourly forecasts, a 7-day forecast, animated weather themes, and interactive temperature charts.

## ✨ Features

- 🌍 **Live Weather Data** — Get current weather information for cities worldwide.
- 🔍 **City Search** — Search for any city by name.
- 📍 **Current Location** — Get weather using your device's location.
- 🌡️ **Temperature Converter** — Switch between Celsius (°C) and Fahrenheit (°F).
- ☀️ **Dynamic Weather Themes** — Background changes according to sunny, cloudy, rainy, snowy, foggy, or stormy conditions.
- 🎨 **Weather Animations** — Animated backgrounds, floating effects, and weather particles.
- 💧 **Weather Highlights** — View humidity, wind speed, pressure, precipitation, and UV index.
- 🕒 **Hourly Forecast** — See the upcoming 24 hours of weather.
- 📅 **7-Day Forecast** — Plan your week with daily weather predictions.
- 📈 **Temperature Chart** — Visualize temperature trends for the next 12 hours.
- 🌅 **Sunrise and Sunset** — View daily sunrise, sunset, and daylight duration.
- 📱 **Responsive Design** — Works on desktops, tablets, and mobile devices.
- 🔑 **No API Key Required** — Uses the Open-Meteo weather API.

## 🛠️ Technologies Used

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/chandradip-17/weather-forecast-app.git
```

### 2. Open the project folder

```bash
cd weather-forecast-app
```

### 3. Run the application

Open the project using Visual Studio Code and launch `index.html` with the Live Server extension.

You can also use another local development server.

This project uses the free Open-Meteo APIs:

- Geocoding API: https://open-meteo.com/en/docs/geocoding-api

No API key is required for normal non-commercial use. Please review the provider's terms and usage limits before deployment or commercial use.
