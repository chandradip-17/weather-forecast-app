## ✨ Features

- 🌤️ **Live Weather Updates** — Get current weather information for cities around the world.
- 🔍 **City Search** — Search for any city and view its weather details.
- 📍 **Current Location** — Get weather information using your device's location.
- 🌡️ **Temperature Conversion** — Switch between Celsius (°C) and Fahrenheit (°F).
- 🎨 **Dynamic Weather Themes** — Background themes change according to weather conditions.
- ✨ **Smooth Animations** — Animated backgrounds, floating effects, and weather particles.
- 🕒 **Hourly Forecast** — View upcoming hourly weather and temperature.
- 📅 **7-Day Forecast** — Check the weather forecast for the next seven days.
- 📊 **Temperature Chart** — Visualize upcoming temperature changes.
- 💧 **Weather Details** — Humidity, wind speed, pressure, precipitation, and UV index.
- 🌅 **Sunrise & Sunset** — View daily sunrise and sunset times.
- 📱 **Responsive Design** — Works on desktop, tablet, and mobile devices.
- 🔑 **No API Key Required** — Uses the Open-Meteo API.

## 🚀 Getting Started

Follow these steps to run Atmos on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/chandradip-17/weather-forecast-app.git
```

### 2. Open the Project Folder

```bash
cd weather-forecast-app
```

### 3. Run the Application

Open the project in Visual Studio Code and launch `index.html` using the Live Server extension.

You can also open `index.html` directly in your browser.

## 🌍 API Used

Atmos uses the **Open-Meteo API** to retrieve weather information.

- Weather Forecast API: https://open-meteo.com/en/docs
- Geocoding API: https://open-meteo.com/en/docs/geocoding-api

No API key is required for normal non-commercial use. Please check Open-Meteo's current terms and usage limits before commercial use.
